# Site fonts

Manrope (normal) and Newsreader (normal and italic) are self-hosted variable
fonts, converted from the Google Fonts TrueType releases to WOFF2 with
FontTools. The full supplied character sets and variation axes are retained.

- Source: https://github.com/google/fonts/tree/main/ofl/manrope
- Source: https://github.com/google/fonts/tree/main/ofl/newsreader
- License: SIL Open Font License 1.1; see the accompanying OFL files.

Fetched 17 November 2026. Manrope is used at weights 400–600; Newsreader at
400–500 with automatic optical sizing. No runtime font service is required.
